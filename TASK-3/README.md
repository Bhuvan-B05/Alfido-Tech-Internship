# Instagram Data Analysis

## Overview

This project was completed as part of my **Data Science Internship at Alfido Tech**. The objective was to analyze Instagram engagement data to identify posting patterns, engagement drivers, and content strategies that can help improve audience growth and interaction.

The analysis focused on engagement metrics, posting schedules, hashtag usage, and follower growth signals to develop actionable recommendations for social media performance.

---

## Dataset

The dataset contains Instagram activity data including:

* Posts
* Likes
* Comments
* Followers
* Hashtags
* Timestamps
* User Interactions

### Dataset Summary

* **Total Posts:** 257
* **Total Likes:** 8,782
* **Total Comments:** 7,488
* **Total Follows:** 7,623

## Key Findings

* **Best Posting Hour:** 8:00 AM
* **Best Posting Day:** Thursday
* Average engagement remained highest during morning posting windows.
* Consistent posting schedules resulted in stronger interaction rates.
* Strategic hashtag usage improved post visibility and engagement.

## Strategies to Increase Engagement

1. Post during peak engagement hours.
2. Use a mix of broad and niche technology hashtags.
3. Increase short-form video and reel content.
4. Encourage audience interaction through questions and polls.
5. Reward active followers through community initiatives and shout-outs.
