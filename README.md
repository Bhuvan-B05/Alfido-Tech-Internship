# Alfido Tech Internship

This repository contains the projects completed as part of my **Data Science Internship at Alfido Tech**. The internship provided hands-on experience in data analysis, machine learning, data visualization, and deriving business insights from real-world datasets.

# Task 1: Zomato Restaurant Data Analysis

## Objective

Analyze restaurant and review data to identify patterns related to customer ratings, cuisine preferences, location trends, pricing, and engagement factors.

## Key Activities

* Data Cleaning and Preprocessing
* Exploratory Data Analysis (EDA)
* Cuisine vs Rating Analysis
* Location Hotspot Analysis
* Price vs Rating Analysis
* Heatmaps and Word Cloud Visualizations
* Business Recommendations

## Key Insights

* Identified top-performing restaurant locations.
* Analyzed the relationship between pricing and customer ratings.
* Discovered cuisine trends and customer preferences.
* Evaluated the impact of online ordering and table booking on ratings.
* Generated business-focused recommendations for a food-tech platform.

## Deliverables

* Jupyter Notebook
* Analysis Report (PDF)
* Visualizations and Insights

# Task 2: Loan Approval Prediction

## Objective

Develop machine learning models to predict loan approval decisions based on applicant information while addressing data preprocessing, feature engineering, and class imbalance challenges.

## Key Activities

* Data Cleaning and Missing Value Handling
* Feature Engineering
* Categorical Variable Encoding
* Feature Scaling
* Class Imbalance Handling using SMOTE
* Model Training and Evaluation
* Business Interpretation of Results

## Models Evaluated

* Logistic Regression
* Decision Tree
* Random Forest
* Gradient Boosting
* XGBoost
* LightGBM

## Evaluation Metrics

* Precision
* Recall
* F1-Score
* ROC-AUC Score

## Key Insights

* Credit history emerged as the most influential factor for loan approval.
* Income and loan amount significantly affected approval decisions.
* Random Forest achieved the strongest overall performance.
* Model evaluation highlighted the importance of balancing prediction accuracy with business risk.

## Deliverables

* Jupyter Notebook
* Machine Learning Report (PDF)
* Model Evaluation Results

# Task 3: Instagram Engagement Analysis

## Objective

Analyze Instagram engagement data to identify optimal posting strategies, engagement drivers, and follower growth opportunities.

## Key Activities

* Data Cleaning and Preprocessing
* Date and Time Analysis
* Engagement Metric Calculation
* Hashtag Analysis
* Posting Schedule Analysis
* Content Performance Analysis
* Strategy Development

## Key Findings

* Best Posting Hour: **8:00 AM**
* Best Posting Day: **Thursday**
* Consistent posting schedules produced higher engagement.
* Strategic hashtag usage improved visibility and reach.
* Audience interaction significantly influenced engagement performance.

## Recommendations for Alfido Tech

1. Publish content during peak engagement periods.
2. Use a balanced mix of broad and niche technology hashtags.
3. Increase educational and community-driven content.
4. Encourage audience interaction through polls, Q&A sessions, and discussions.
5. Continuously monitor analytics and refine the content strategy.

## Deliverables

* Jupyter Notebook
* Instagram Strategy Report (PDF)
* Engagement Analysis Visualizations
